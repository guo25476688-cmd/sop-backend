Dify 工作流字段参考

确保你的 Dify 应用输入变量名与下方一致

A1 · SOP 大纲生成

Workflow 类型

输入变量 activity_name（活动名称）、activity_type（活动类型）、background（活动背景）、date（活动时间）、target（目标对象）、budget（预算上限）、department（创建部门）
输出建议Markdown 格式文本，包含大纲结构

A2 · 执行主表生成

Workflow 类型

输入变量 sop_outline（A1 确认后的大纲文本）、project_info（项目基本信息 JSON）
输出建议Markdown 表格或结构化任务列表

A3 · 配套成果生成

Workflow 类型

输入变量 task_table（A2 确认的执行主表）、project_info（项目信息 JSON）、asset_type（成果类型）
输出建议Markdown 格式，含各类配套文档内容

A4 · AI 修改助手

Chatflow 类型

输入变量 project_context（项目上下文 JSON，含 sop_outline/task_table/assets 等）
注意A4 是对话模式（Chatflow），用户通过 query 发送修改指令

R1 · 活动复盘分析

Workflow 类型

输入变量 event_data（附件数据）、task_table（执行主表）、project_info（项目信息 JSON）、feedback_data（反馈数据）
输出建议分析结论，Markdown 格式

R2 · 复盘报告生成

Workflow 类型

输入变量 r1_analysis（R1 确认的分析结论）、project_info（项目信息 JSON）
输出建议完整复盘报告，Markdown 格式

导出 / 导入

全量数据备份与恢复

📤 导出数据

将配置和全部项目数据导出为 JSON 文件

导出内容包括：API 配置、全部项目及其各模块数据（A1-A4、R1-R2）、版本记录、活动动态。

📥 导入数据

从之前导出的 JSON 文件恢复数据

导入会新增项目记录，不会覆盖已有项目。配置项（API Key 等）会被导入文件中的值替换。
